# Catering Manager (JSON-first Django)
Light theme UI that uses JSON endpoints. No Django forms.

Quickstart:
1) python -m venv venv
2) venv\Scripts\activate  (or source venv/bin/activate)
3) pip install django
4) python manage.py migrate
5) python manage.py shell < scripts/load_sample.py
6) python manage.py runserver
